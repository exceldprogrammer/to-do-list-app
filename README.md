
# To-Do List App

I built this project to improve my web development skills and get more comfortable working with JavaScript.

One of my main goals was to better understand how arrays work and how to use localStorage to save data so that tasks remain even after the page is refreshed. Instead of just watching tutorials, I wanted to learn by actually building something from scratch and solving problems along the way.

While working on this project, I learned and practiced concepts such as:
- Arrays and array methods
- localStorage
- DOM manipulation
- Event listeners
- Dynamic rendering of data
- Writing cleaner and more organized JavaScript code

After I finished building the project, I shared the code with Gemini for a review. It helped identify areas that could be improved, suggested code refinements, and assisted in redesigning the interface using Tailwind CSS to give the application a cleaner and more modern look.

This project is a small step in my journey as a developer, and it helped me gain a much better understanding of JavaScript through hands-on practice.
